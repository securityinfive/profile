# Security In Five Portfolio

Static GitHub Pages portfolio for Security In Five / Drew Koenig.

## Publish

1. Create a public GitHub repository named `securityinfive.github.io` under the `securityinfive` account.
2. Upload these files to the repository root.
3. In repository **Settings → Pages**, set **Build and deployment** to **Deploy from a branch**, then select `main` and `/ (root)`.

The site will be available at `https://securityinfive.github.io`.

## Update content

The site has no dependencies or build step. Core content is in `index.html`; career-section styling is in `resume.css`.
